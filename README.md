# theScreenshotCompany
Perfect for quick file sharing, temporary storage, or situations where you don’t want to sign in your email account just to upload a file.

theScreenshotCompany is a lightweight cloud storage web app that lets users upload screenshots or files and retrieve them later using a unique access key — no email, no signup, no accounts.

The idea is simple:
get a key → Upload a file → use the key anytime to download the file.
